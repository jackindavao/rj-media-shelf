First project: The Tiny Bird's Garden

A one-room game is enough: walk through a small garden, find three seeds, and make a flower appear. The purpose is to discover that a game is made from understandable pieces.

1. Build without code. Install Roblox Studio from Roblox's official site with the adult present. Start from a simple baseplate. Add ground, three platforms, a flowerbed, and a clear start and finish.
2. Test after every tiny change. Use Play, move with keyboard and mouse, stop, and change one thing. RJ should be able to say what changed and why.
3. Add one behavior. Make a seed disappear when touched and increase a visible seed count. Use a short script only after the no-code world makes sense.
4. Let AI explain, not take over. Ask for one small change at a time: “Explain every line of a Roblox Lua script that hides this seed when a player touches it.” Read the answer together. Do not paste opaque models or scripts into the project.
5. Keep the first game private. Save versions locally or privately. Publishing, public play, monetization, free models, and collaboration are later adult decisions—not requirements for learning.

Good creator questions while playing

  • How does the game teach the controls?
  • What is the smallest repeated rule?
  • Where can the player make a real choice?
  • How does color or shape guide the eye?
  • Where is a fair place to stop?
  • Could we build a tiny version with one room and one rule?

Adult expectations

Roblox describes Studio as a Windows/macOS creation tool and its education material generally targets learners around age ten and up. At eight, RJ can still begin successfully if the adult handles account, installation, publishing, and safety while RJ owns the design choices, testing, naming, and gradually the code. A tiny finished game is far more valuable than a giant AI-generated one she cannot explain.

RJ's first goal is not “be a programmer.” It is “I can make one thing happen on purpose.”
